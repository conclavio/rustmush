# Doctrine

The free Stickney teaching library explains Standard Doctrine's six presets.
It reads the actual cards built from this server's current configuration:

  @mind/doctrine
  @mind/doctrine Line
  @mind/doctrine Sentry
  @mind/doctrine Sniper
  @mind/doctrine Skirmisher
  @mind/doctrine Hunter
  @mind/doctrine Rearguard

The index gives a short lesson for each preset. A named page shows its current
range band, firing odds and aspect, ammunition reserve, targeting weights,
retreat thresholds, rally, search and hunting times. Preset names ignore case.

Each card is an armed example. Fire terms cannot act on a hull without weapons.
Fields marked `[inert]` are stored card values that Standard Doctrine does not
fly: a Skirmisher does not orbit and a Sentry holds no screen arc. The page
marks those fields explicitly rather than promising behavior from their names.

Reading a page changes no selection, draft, profile or running sortie. These
pages are public teaching content; they do not read another pilot's library.

In the simulator lobby, `SIM MIND Standard PROFILE Sniper` selects the stock
Sniper profile. `MIND CARD` in the cockpit reads the actual sealed card on your
hull. `help minds` explains selection and switching; `help mindcraft` explains
private authoring and `@mind/source Standard` reads the shipped reference source.
