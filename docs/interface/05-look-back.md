# I1–I13 look-back

**Status:** Draft 0.1 — 2026-09-07. The owner's audit of the interface programme (I1–I13, [02](02-implementation-plan.md)) before it is declared done. Code and plan are grounded at `673db4c` (branch `interface-i11`, "Interface plan Draft 1.3"). Inputs: thirteen per-cut claim extractions (576 claims from the commits, the plan's design and as-built paragraphs, and §6–§9), a verifier pass over every claim, a refuter pass over every `partial`/`missing`, and three debt lenses (deferral chain, cross-cut conventions, standing debt). Every `file:line` is at `673db4c` unless a commit hash is given; `plan:n` is 02-implementation-plan.md line n. §7 is the single fold list.

## 1. Verdict and totals

Yes, with qualifications. Of 576 claims, 506 (87.8%) are implemented as stated, 6 were superseded by a later documented cut, 62 were partial and 2 missing. The refuters overturned 35 of the 64 — the claim quoted the design half of a section its own as-built had amended, misread a count, or named a file ts-rs cannot emit — leaving **29 confirmed gaps**: 1 high, 5 medium, 23 low. None leaks another character's data and none fires a mutating command from a bare key (the P lens and D-I-18 held everywhere they were attacked). The one high gap is a live bug: a connected web player's vitals watermark survives a server restart while the world's `VitalsRevisions` restarts at 0, so after the first deploy-time restart every gauge is stale for the rest of the session (I1-C4). The five mediums: the web drops every Shadowrun roll frame and `+init/roll` never reaches `sr.roll` (I6-C11); Enter on the TUI's channel screen prefills nothing on a stock server (I7-C12); `Query::NarrativeBacklog` has no serde round-trip anywhere (I12-C2); the strict query-flood check has no test and its `_at` twin is a dead copy (I12-C6); `GameApp.act`, the web's whole modal-key model, is untested (I4-C45). The rest are test and doc gaps.

The debt lenses found more than the claim audit did, because they read the seams between cuts rather than inside them: four HIGH code items — the web `/clear` re-arms the backlog and repaints the lines just cleared (LB-1), `feedScreens` survives a character switch so the unit screen is silently refused (LB-2), a generic-view screen's `r` refreshes WHO (LB-3), and `GenericView` keys wire-supplied columns by producer id, the `each_key_duplicate` crash the I8 fold fixed in `KeyValue` and missed here (LB-4) — and three structural facts: I8 is unreachable in production because the tactics module composes with an empty catalog (LB-6), seven of thirteen cuts never had the adversarial verify §4 rule 3 requires (LB-5), and the contact-id security finding was handed to a programme that never received it (LB-34).
